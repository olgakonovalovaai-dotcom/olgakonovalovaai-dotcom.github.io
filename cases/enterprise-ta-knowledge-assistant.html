Enterprise Knowledge Assistant

Helping recruiters find reliable answers across internal knowledge sources.

Domain Global Talent Acquisition
Role AI Automation Business Analyst · End-to-End Solution Development
Tech stack Copilot Studio · Azure AI Search · Azure OpenAI · Azure Functions · Python
Status Production rollout in progress

The challenge

The knowledge was approved. Finding it was not.

Recruiters rely on an extensive internal knowledge base covering hiring processes, policies, and tools. Finding accurate guidance often means searching through multiple pages and checking whether the information is still relevant.

I built an AI assistant to make approved knowledge easier to access, with answers that link directly to their original sources.

What I built

I independently designed and developed the solution.

The work covered business analysis, architecture, implementation, and testing.

Knowledge processing. Built an Azure Functions pipeline to extract, clean, and index internal documentation.
Retrieval. Implemented hybrid keyword and vector search with semantic reranking in Azure AI Search.
AI agent. Developed a Copilot Studio agent with source citations, knowledge restrictions, and fallback behaviour.
Evaluation. Created a retrieval test set, measured search quality, and refined the solution based on the findings.

Solution architecture

Approved knowledge, retrieved, then cited.

The assistant uses Retrieval-Augmented Generation (RAG) to connect natural-language questions with approved internal knowledge.

Documents are processed into searchable sections, preserving their original context and source references. Hybrid retrieval combines exact keyword matching with semantic search to identify relevant information.

The agent uses retrieved content to answer questions, cite sources, and handle queries that fall outside the available knowledge.

Key design decisions

Scope, retrieval, and a source the recruiter can check.

Controlled knowledge scope

Restricted retrieval to approved documentation to reduce the risk of unsupported guidance.

Hybrid retrieval

Combined keyword search, vector similarity, and semantic reranking to handle both exact terminology and natural-language questions.

Source traceability

Preserved document metadata and defined citation and fallback requirements so recruiters can verify the information they receive.

Outcome

A working assistant, now in rollout.

I delivered a working enterprise AI assistant with a custom knowledge processing pipeline, hybrid retrieval, and a Copilot Studio interface.

The solution is progressing through production rollout and is designed to make internal guidance easier to find, more consistent, and verifiable through source references.

The project brought together business analysis, AI architecture, hands-on development, and quality evaluation — from the initial business problem to an implemented solution.
